## 1. 프로젝트 개요 (한눈에 보기)

### 프로젝트 목적
- 고전 아케이드 게임 '보글보글(Bubble Bobble)'의 핵심 플레이를 웹 브라우저(Canvas HTML5)에서 완벽히 즐길 수 있도록 구현합니다.
- 아이디/비밀번호 기반의 회원가입 및 로그인을 제공하여, 게임 진행 상황(스테이지, 점수, 남은 목숨)을 서버에 실시간 저장하고 언제 어디서나 이어서 진행할 수 있습니다.

### 주요 특징
- **플랫폼 가리지 않는 호환성**: PC(키보드 안내 바 제공) 및 모바일(가상 터치 키패드) 동시 지원
- **안전한 데이터 관리**: Neon PostgreSQL 서버리스 데이터베이스를 활용한 회원 정보 및 세이브/랭킹 스코어 지속성 확보
- **즉시 플레이**: 비회원(게스트) 즉시 시작 모드 및 단일 클릭 회원가입/로그인 지원
- **배포 자동화**: GitHub push 연동 Vercel 자동 배포 환경 구축

## 2. 사용자와 사용 시나리오

### 사용자 유형
- **비회원(게스트) 사용자**: 로그인 없이 즉시 게임을 시작할 수 있으나, 브라우저 종료 시 진행 상황이 저장되지 않음.
- **회원 사용자**: 아이디/패스워드로 로그인하여 스테이지 진행도와 최고 점수를 영구 저장 및 동기화함.

### 주요 사용 시나리오
1. 사용자가 메인 화면에서 로그인 또는 '비회원 시작'을 선택합니다.
2. 로그인 시, 기존에 진행하던 스테이지와 점수를 불러와 게임 화면으로 진입합니다.
3. 방향키와 액션키(방울 발사, 점프)를 사용해 적을 가두고 터뜨리며 스테이지를 클리어합니다.
4. 게임 도중 창을 닫아도 로그인 계정에 최종 스테이지가 자동 저장됩니다.

## 3. 기능 명세

### 1. 인증 기능
- **회원가입**: 아이디(영문/숫자 4~20자), 비밀번호(6자 이상) 입력 (비밀번호는 `bcrypt`로 암호화하여 저장)
- **로그인/로그아웃**: HttpOnly 쿠키 기반 세션 또는 JWT 토큰 발급
- **게스트 플레이**: 계정 없이 즉시 플레이 가능 (진행 상황 DB 세이브 불가, 브라우저 세션 동안만 임시 유지)

### 2. 게임플레이 및 물리/인터랙션 메커니즘
- **이동 및 점프**: 좌우 방향키(`ArrowLeft`, `ArrowRight`)로 수평 이동, 점프키(`Space`)로 발판 위아래 점프
- **방울 직선 발사 및 리셋 방지 규칙**:
  - 방울 발사 키(`Z`) 입력 시, 브라우저 기본 동작 및 Form 전송 방지를 위해 `e.preventDefault()`를 필수 실행함
  - 방울 생성 시 전체 게임 State(점수, 목숨, 스테이지 번호)를 절대로 재초기화하지 않고, 발사체의 객체(`bubbles` 배열)만 추가 갱신함
  - 발사 키 누름 지속(Key Hold) 시 연사가 과도하게 발생하는 것을 방지하기 위해 발사 쿨타임(예: 0.25초) 적용
  - 캐릭터 전방 방향으로 지면과 수평한 직선 궤적으로 약 250px 발사된 후 상단 부유 상태로 전환
- **적 포획**: 발사 중인 방울이 적 캐릭터와 충돌하면 적이 방울 내부에 즉시 포획되어 둥둥 떠오름
- **방울 터뜨리기 및 적 처치**:
  - 플레이어 캐릭터가 방울(빈 방울 또는 적이 갇힌 방울)과 부딪히면 방울이 터짐
  - 방울 안에 적 캐릭터가 들어있는 상태에서 플레이어가 부딪히면 적과 방울이 함께 터지며 적이 처치되고 100점 획득
- **스테이지 진행**: 맵 내의 모든 적을 처치하면 스테이지 클리어 효과 후 다음 스테이지로 즉시 이동 (기본 총 5개 스테이지 순환)
- **게임 오버**: 목숨(`lives`)이 0이 되면 게임 오버 화면 노출 및 최종 점수 표시

### 3. 디바이스별 조작 인터페이스
- **PC 환경 (화면 폭 768px 이상 & 마우스/키보드 감지)**: 화면상의 가상 터치 버튼을 완전히 숨기고, 캔버스 하단에 `[← / →]: 이동 | [Space]: 점프 | [Z]: 방울 발사` 형태로 한 줄 텍스트 안내 고정 표시
- **모바일/터치 환경**: 화면 하단에 가상 D-Pad(좌/우)와 액션 버튼(JUMP, BUBBLE) 노출

### 4. 세이브/로드 및 랭킹
- 회원 로그인 상태일 경우, 스테이지 클리어 시점 및 게임 오버 시 현재 스테이지, 누적 점수, 남은 목숨을 DB에 자동 저장
- 재로그인 시 저장된 스테이지부터 즉시 '이어하기' 선택 가능
- 게임 오버 시 개인 최고 점수가 DB에 갱신되며 전체 랭킹에 반영

## 5. 데이터 모델

### 데이터베이스 스키마 (Neon PostgreSQL)

모든 DB 접근은 Next.js 서버 컴포넌트 또는 `/app/api` 라우트 핸들러를 통해서만 실행되며, 클라이언트에 자격 증명이 노출되지 않습니다.

#### 1. `users` (사용자 계정)
| 컬럼명 | 데이터 타입 | 제약 조건 | 설명 |
| --- | --- | --- | --- |
| `id` | SERIAL | PRIMARY KEY | 고유 사용자 번호 |
| `username` | VARCHAR(50) | UNIQUE, NOT NULL | 사용자 로그인 아이디 |
| `password_hash` | VARCHAR(255) | NOT NULL | bcrypt 단방향 암호화 해시 |
| `created_at` | TIMESTAMP | NOT NULL, DEFAULT NOW() | 가입 일시 |

#### 2. `game_saves` (진행도 및 최고 기록)
| 컬럼명 | 데이터 타입 | 제약 조건 | 설명 |
| --- | --- | --- | --- |
| `id` | SERIAL | PRIMARY KEY | 세이브 고유 번호 |
| `user_id` | INT | NOT NULL, UNIQUE, REFERENCES `users(id)` ON DELETE CASCADE | 사용자 외래키 |
| `stage` | INT | NOT NULL, DEFAULT 1 | 현재 진행 스테이지 (1~5) |
| `score` | INT | NOT NULL, DEFAULT 0 | 현재 누적 점수 |
| `high_score` | INT | NOT NULL, DEFAULT 0 | 개인 최고 점수 (순위표 연동) |
| `lives` | INT | NOT NULL, DEFAULT 3 | 남은 목숨 수 |
| `updated_at` | TIMESTAMP | NOT NULL, DEFAULT NOW() | 마지막 세이브 일시 |

### 주요 쿼리 규칙
- **랭킹 조회**: `SELECT u.username, g.high_score, g.updated_at FROM game_saves g JOIN users u ON g.user_id = u.id ORDER BY g.high_score DESC LIMIT 50;`
- **세이브 갱신**: 스테이지 완료 시 `stage`, `score`, `lives`를 UPDATE하며, 기존 `high_score`보다 현재 `score`가 높으면 `high_score`도 함께 갱신

## 10. 테스트 계획

### 스모크 테스트 (Smoke Routes)
배포 후 로그인/DB 없이 즉시 HTTP 200으로 접근 가능한 경로:
- `GET /`: 메인 랜딩 화면 정상 렌더링 확인
- `GET /game`: 게스트 상태로 즉시 캔버스 실행 및 키 안내 확인
- `GET /help`: 조작법 및 방울 규칙 설명 텍스트 표시 확인
- `GET /login`: 로그인 폼 입력 필드 및 버튼 노출 확인
- `GET /signup`: 회원가입 폼 입력 필드 노출 확인
- `GET /ranking`: 랭킹 화면 스켈레톤 및 빈 순위 테이블 정상 렌더링 확인

### 기능별 수용 기준 (Given / When / Then)

#### 1. 방울 발사 시 게임 유지 및 방울 생성
- **Given**: 플레이어가 게임 진행 중(점수 100점, 목숨 3개 상태) 상태임
- **When**: 플레이어가 `Z` 키를 누름
- **Then**: 페이지가 새로고침되거나 게임 진행 상태가 초기화되지 않고, 플레이어 위치 바로 앞 방향으로 방울 발사체가 생성되어 이동함

#### 2. 방울 직선 발사 및 적 포획
- **Given**: 플레이어와 적 몬스터가 같은 수평선상에 위치함
- **When**: 플레이어가 `Z` 키(또는 모바일 BUBBLE 버튼)를 입력함
- **Then**: 방울이 발사 방향으로 즉시 직선 이동하며, 적과 접촉 시 해당 적이 방울 내부에 포획되어 상단으로 서서히 떠오름

#### 3. 방울 터뜨리기 및 점수 획득
- **Given**: 적이 갇힌 방울이 공중에 부유하고 있음
- **When**: 플레이어 캐릭터가 방울의 충돌 반경(히트박스)에 닿음
- **Then**: 방울과 내부의 적이 팝 효과와 함께 동시에 제거되며 스코어가 100점 추가됨

#### 4. PC 환경 전용 조작 안내 노출
- **Given**: 화면 너비 768px 이상의 PC 브라우저 환경에서 `/game` 접속
- **When**: 화면 캔버스 영역 하단을 확인함
- **Then**: 가상 버튼 UI가 렌더링되지 않으며, `[← / →] 이동 | [Space] 점프 | [Z] 방울 발사` 문구가 단일 라인으로 표시됨

#### 5. 로그인 사용자 세이브 및 복원
- **Given**: 회원 사용자가 스테이지 2 진행 중 창을 닫음
- **When**: 동일 계정으로 재로그인 후 `/game`으로 진입함
- **Then**: 저장되었던 스테이지 2와 이전 점수가 그대로 복원되어 시작됨
