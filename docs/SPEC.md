## 1. 프로젝트 개요 (한눈에 보기)

### 프로젝트 목적
- 고전 아케이드 게임 '보글보글(Bubble Bobble)'의 핵심 플레이를 웹 브라우저에서 즐길 수 있도록 구현합니다.
- 아이디/비밀번호를 통한 회원가입 및 로그인을 지원하여, 게임 진행 상황(스테이지, 점수 등)을 서버에 저장하고 언제 어디서나 이어서 할 수 있습니다.

### 주요 특징
- PC 및 모바일(가상 키패드 지원) 환경에서 플레이 가능
- Neon PostgreSQL을 활용한 사용자 계정 및 세이브 데이터 관리
- Vercel을 통한 빠르고 안정적인 배포

## 2. 사용자와 사용 시나리오

### 사용자 유형
- **비회원(게스트) 사용자**: 로그인 없이 즉시 게임을 시작할 수 있으나, 브라우저 종료 시 진행 상황이 저장되지 않음.
- **회원 사용자**: 아이디/패스워드로 로그인하여 스테이지 진행도와 최고 점수를 영구 저장 및 동기화함.

### 주요 사용 시나리오
1. 사용자가 메인 화면에서 로그인 또는 '비회원 시작'을 선택합니다.
2. 로그인 시, 기존에 진행하던 스테이지와 점수를 불러와 게임 화면으로 진입합니다.
3. 방향키와 액션키(방울 발사, 점프)를 사용해 적을 가두고 터뜨리며 스테이지를 클리어합니다.
4. 게임 도중 창을 닫아도 로그인 계정에 최종 스테이지가 자동 저장됩니다.

## 3. 기능 명세

### 1. 인증 기능
- **회원가입**: 아이디, 비밀번호 입력 (비밀번호는 안전하게 암호화하여 저장)
- **로그인/로그아웃**: 세션 기반 인증
- **게스트 플레이**: 계정 없이 바로 플레이 (세이브 불가)

### 2. 게임플레이 기능
- **이동 및 점프**: 좌우 이동, 점프
- **방울 공격**: 방울을 발사하여 적을 가두기
- **적 처치**: 방울 속 적을 건드려 터뜨리기
- **스테이지 진행**: 모든 적을 처치하면 다음 스테이지로 이동

### 3. 도움말 및 조작법 안내 기능
- **조작법 설명**: 키보드 및 모바일 가상 패드 사용법 안내 (방향키, 점프, 방울 발사)
- **게임 규칙 안내**: 적을 가두고 터뜨리는 방법, 아이템 효과 등 설명 페이지 제공

### 4. 세이브/로드 기능
- 스테이지 클리어 시 또는 게임 종료 시 현재 스테이지, 점수, 남은 목숨을 DB에 자동 저장
- 재로그인 시 저장된 스테이지부터 재개

## 4. 화면과 주소(URL) 구성

### URL 경로 구조
| 경로 | 화면 이름 | 설명 |
| --- | --- | --- | 
| `/` | 메인 화면 | 로그인, 회원가입, 비회원 시작, 도움말 이동 버튼 제공 |
| `/login` | 로그인 화면 | 아이디, 비밀번호 입력 폼 |
| `/signup` | 회원가입 화면 | 아이디, 비밀번호, 비밀번호 확인 폼 |
| `/game` | 게임 플레이 화면 | 캔버스 기반 게임 화면, 점수판, 조작 패드(모바일), 일시정지 및 도움말 호출 버튼 |
| `/help` | 도움말 화면 | 게임 조작법 및 플레이 규칙 상세 안내 |
| `/ranking` | 순위표 화면 | 전체 사용자의 최고 점수 순위 표시 |

### 화면별 상세
- **메인 (`/`)**:
  - 배경색: `#111111` (어두운 테마)
  - 버튼: `#FF5722` (주황색, 보글보글 감성)
- **도움말 (`/help`)**:
  - 키보드 조작 안내 (←/→ 이동, 공간키 점프, Z키 방울 발사)
  - 모바일 터치 패드 안내 및 게임 규칙 설명
- **게임 화면 (`/game`)**:
  - 상단: 플레이어 이름, 현재 점수, 남은 목숨, 현재 스테이지 표시
  - 중앙: 800x600 픽셀 게임 캔버스
  - 하단: (모바일용) 가상 조이스틱 및 액션 버튼

## 5. 데이터 모델

### 데이터베이스 테이블 (Neon PostgreSQL)

#### 1. `users` (사용자 테이블)
- `id` (SERIAL, Primary Key)
- `username` (VARCHAR(50), Unique, Not Null): 사용자 아이디
- `password_hash` (VARCHAR(255), Not Null): 암호화된 비밀번호
- `created_at` (TIMESTAMP, Default: NOW())

#### 2. `game_saves` (게임 진행 상황 테이블)
- `id` (SERIAL, Primary Key)
- `user_id` (INT, Foreign Key to `users.id`, Unique)
- `stage` (INT, Default: 1): 현재 클리어해야 할 스테이지 번호
- `score` (INT, Default: 0): 누적 점수
- `lives` (INT, Default: 3): 남은 목숨
- `updated_at` (TIMESTAMP, Default: NOW()): 마지막 저장 시간

## 10. 테스트 계획

### 수용 기준 (Given / When / Then)

#### 1. 회원가입 및 로그인
- **Given**: 사용자가 `/signup` 페이지에 접속해 아이디 `player1`, 비밀번호 `password123`을 입력한다.
- **When**: '가입하기' 버튼을 클릭한다.
- **Then**: 계정이 성공적으로 생성되고 `/login` 페이지로 리다이렉트된다.

#### 2. 게임 세이브 및 이어하기
- **Given**: 로그인한 사용자가 `stage: 3`, `score: 1500`, `lives: 2` 상태로 플레이 중이다.
- **When**: 사용자가 브라우저 창을 닫고 다시 로그인하여 `/game`에 접속한다.
- **Then**: 데이터베이스에서 최신 세이브 정보를 불러와 `stage: 3`, `score: 1500`, `lives: 2` 상태로 게임이 즉시 복원된다.

#### 3. 조작법 및 도움말 확인
- **Given**: 사용자가 `/` 또는 `/game` 화면에 있다.
- **When**: '도움말/조작법' 버튼을 클릭한다.
- **Then**: `/help` 페이지로 이동하여 키보드(방향키, 공간키, Z키) 및 모바일 터치 패드 사용법, 적을 가두고 터뜨리는 게임 규칙을 확인할 수 있다.
