## 1. 테스트 계획

### 스모크 테스트 (Smoke Routes)
배포 후 로그인/DB 없이 즉시 HTTP 200으로 접근 가능한 경로:
- `GET /`: 메인 랜딩 화면 정상 렌더링 확인
- `GET /game`: 게스트 상태로 즉시 캔버스 실행 및 키 안내 확인
- `GET /help`: 조작법 및 방울 규칙 설명 텍스트 표시 확인
- `GET /login`: 로그인 폼 입력 필드 및 버튼 노출 확인
- `GET /signup`: 회원가입 폼 입력 필드 노출 확인
- `GET /ranking`: 랭킹 화면 스켈레톤 및 빈 순위 테이블 정상 렌더링 확인

### 기능별 수용 기준 (Given / When / Then)

#### 1. 방울 발사 시 게임 유지 및 방울 생성
- **Given**: 플레이어가 게임 진행 중(점수 100점, 목숨 3개 상태) 상태임
- **When**: 플레이어가 `Z` 키를 누름
- **Then**: 페이지가 새로고침되거나 게임 진행 상태가 초기화되지 않고, 플레이어 위치 바로 앞 방향으로 방울 발사체가 생성되어 이동함

#### 2. 방울 직선 발사 및 적 포획
- **Given**: 플레이어와 적 몬스터가 같은 수평선상에 위치함
- **When**: 플레이어가 `Z` 키(또는 모바일 BUBBLE 버튼)를 입력함
- **Then**: 방울이 발사 방향으로 즉시 직선 이동하며, 적과 접촉 시 해당 적이 방울 내부에 포획되어 상단으로 서서히 떠오름

#### 3. 방울 터뜨리기 및 점수 획득
- **Given**: 적이 갇힌 방울이 공중에 부유하고 있음
- **When**: 플레이어 캐릭터가 방울의 충돌 반경(히트박스)에 닿음
- **Then**: 방울과 내부의 적이 팝 효과와 함께 동시에 제거되며 스코어가 100점 추가됨

#### 4. PC 환경 전용 조작 안내 노출
- **Given**: 화면 너비 768px 이상의 PC 브라우저 환경에서 `/game` 접속
- **When**: 화면 캔버스 영역 하단을 확인함
- **Then**: 가상 버튼 UI가 렌더링되지 않으며, `[← / →] 이동 | [Space] 점프 | [Z] 방울 발사` 문구가 단일 라인으로 표시됨

#### 5. 로그인 사용자 세이브 및 복원
- **Given**: 회원 사용자가 스테이지 2 진행 중 창을 닫음
- **When**: 동일 계정으로 재로그인 후 `/game`으로 진입함
- **Then**: 저장되었던 스테이지 2와 이전 점수가 그대로 복원되어 시작됨

## 2. 배포와 운영

### 배포 및 운영
- **호스팅 플랫폼**: Vercel
- **데이터베이스**: Neon Console을 통한 DB 생성 및 연결
- **환경 변수 설정**:
  - `DATABASE_URL`: Neon PostgreSQL 연결 문자열
  - `NEXTAUTH_SECRET` 또는 세션 암호화 키
- **배포 프로세스**: `main` 브랜치에 코드가 푸시되면 Vercel이 자동 빌드 및 배포 수행
