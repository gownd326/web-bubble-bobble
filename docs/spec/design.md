## 1. 화면과 주소(URL) 구성

### URL 경로 구조
| 경로 | 화면 이름 | 설명 |
| --- | --- | --- |
| `/` | 메인 화면 | 로그인, 회원가입, 비회원 시작, 도움말 이동 버튼 제공 |
| `/login` | 로그인 화면 | 아이디, 비밀번호 입력 폼 |
| `/signup` | 회원가입 화면 | 아이디, 비밀번호, 비밀번호 확인 폼 |
| `/game` | 게임 플레이 화면 | 캔버스 기반 게임 화면, 점수/목숨/스테이지 HUD, 디바이스 반응형 조작 UI |
| `/help` | 도움말 화면 | 게임 조작법 및 방울 공격/터뜨리기 규칙 상세 안내 |
| `/ranking` | 순위표 화면 | 전체 사용자의 최고 점수 순위 표시 |

### `/game` 화면 레이아웃 및 디바이스 분기 상세
- **상단 HUD 영역**:
  - 플레이어 이름, 점수(`SCORE: 00000`), 남은 목숨(`♥ x 3`), 현재 스테이지(`STAGE 1`), 일시정지 버튼
- **중앙 게임 영역**:
  - 800x600 픽셀 기준 고정 비율 게임 캔버스
- **하단 컨트롤/안내 영역 (디바이스 감지 분기)**:
  - **PC 브라우저 (화면 너비 768px 이상 또는 마우스/키보드 환경)**:
    - 가상 버튼 미노출(숨김 처리)
    - 캔버스 하단 텍스트 바: `[← / →] 이동 | [Space] 점프 | [Z] 방울 발사` (중앙 정렬, 레트로 폰트, `#cccccc` 색상)
  - **모바일 브라우저 (터치 스크린 환경)**:
    - 좌측: 가상 좌우 방향 패드
    - 우측: `JUMP`(점프) 버튼, `BUBBLE`(발사) 버튼

## 2. 디자인 가이드

### 디자인 시스템
- **색상 팔레트**:
  - 배경: `#1a1a2e` (다시 네이비)
  - 주요 강조색: `#e94560` (레온 핑크/레드)
  - 보조 색상: `#0f3460` (블루 계열)
  - 텍스트: `#ffffff` (흰색)
- **폰트**:
  - 구글 폰트 'DungGeunMo' (둥근모꼴, 레트로 게임풍 폰트)
- **반응형 규칙**:
  - PC: 고정 크기 캔버스 중앙 정렬
  - 모바일: 화면 너비에 맞게 캔버스 비율 유지 축소 및 하단 터치 패드 노출
