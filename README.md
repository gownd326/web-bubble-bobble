# 웹 보글보글 (Web Bubble Bobble)

고전 아케이드 명작 게임 '보글보글(Bubble Bobble)'의 핵심 플레이를 웹 브라우저에서 즐길 수 있는 레트로 아케이드 웹 게임입니다.

---

## 🎮 주요 기능 및 특징
- **PC & 모바일 반응형 조작 UI**:
  - **PC 브라우저 (너비 768px 이상)**: 가상 버튼을 자동으로 숨기고 `[← / →] 이동 | [Space] 점프 | [Z] 방울 발사` 단일 라인 조작 안내를 표시합니다.
  - **모바일/터치 브라우저**: 좌측 이동 D-Pad와 우측 JUMP / BUBBLE 가상 터치 버튼이 노출됩니다.
- **게임 물리 & 인터랙션**:
  - **방울 직선 발사**: Z 키를 누르면 캐릭터 전방으로 지면과 수평한 직선 궤적으로 약 250px 발사된 후 부유 상태로 전환됩니다.
  - **적 포획**: 발사 중인 방울이 적과 접촉하면 적이 방울 내부에 즉시 포획되어 둥둥 떠오릅니다.
  - **방울 터뜨리기 & 적 처치**: 플레이어가 갇힌 방울과 부딪히면 적과 방울이 함께 터지며 100점을 획득합니다.
  - **스테이지 진행**: 모든 적을 처치하면 총 5개의 스테이지를 순환 진행합니다.
- **회원가입 및 세이브 시스템**:
  - 회원 로그인 시 스테이지, 누적 점수, 최고 점수(high_score)가 Neon PostgreSQL DB에 자동 동기화되어 재로그인 시 저장된 스테이지부터 이어할 수 있습니다.
- **게스트 플레이**: 로그인 없이 즉시 비회원 플레이가 가능합니다.
- **명예의 전당 (순위표)**: 전체 회원의 최고 점수 상위 50위를 실시간 제공합니다.

## 🛠️ 기술 스택
- **프레임워크**: Next.js 14+ (App Router)
- **언어**: TypeScript
- **데이터베이스**: Neon PostgreSQL (`@neondatabase/serverless`)
- **비밀번호 암호화**: `bcryptjs`
- **스타일링**: Tailwind CSS (구글 폰트 DungGeunMo 적용)
- **테스트**: Vitest

## 💻 비전문가를 위한 실행 가이드 (로컬 실행 방법)

컴퓨터에 Node.js가 설치되어 있지 않다면, [Node.js 공식 홈페이지](https://nodejs.org/)에서 LTS 버전(Node.js 20 이상)을 설치해 주세요.

### 1. 프로젝트 폴더 이동
터미널을 열고 프로젝트 폴더로 이동합니다.
```bash
cd web-bubble-bobble
```

### 2. 패키지 설치
아래 명령어를 입력하여 필요한 라이브러리를 설치합니다.
```bash
npm install
```

### 3. 환경 변수 설정
`.env.example`을 참고하여 `.env.local` 파일을 생성할 수 있습니다. (DB가 없어도 빌드와 게스트 플레이는 문제없이 작동합니다.)
```env
DATABASE_URL=postgres://user:password@host:5432/database?sslmode=require
SESSION_SECRET=your-super-secret-key-32-chars-long-here
```

### 4. 개발 서버 시작
다음 명령어로 웹 서버를 실행합니다.
```bash
npm run dev
```

### 5. 게임 플레이 접속
브라우저를 열고 주소창에 아래 URL을 입력합니다.
- `http://localhost:3000`
