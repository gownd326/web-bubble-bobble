# 웹 보글보글 (Web Bubble Bobble)

고전 아케이드 게임 '보글보글(Bubble Bobble)'의 핵심 플레이를 웹 브라우저에서 즐길 수 있는 레트로 아케이드 웹 게임입니다.

---

## 🚀 주요 기능
- **회원가입 및 로그인**: 계정을 생성하고 로그인하여 스테이지와 점수를 서버에 안전하게 저장합니다.
- **게스트 플레이**: 로그인 없이 즉시 게임을 시작하여 가볍게 즐길 수 있습니다.
- **게임 플레이**: 방향키로 이동 및 점프, Z키(또는 액션 버튼)로 방울을 발사하여 적을 가두고 터뜨릴 수 있습니다.
- **랭킹 시스템**: 전체 사용자의 최고 점수 순위를 확인할 수 있습니다.
- **모바일 지원**: 가상 조이스틱과 터치 패드를 제공하여 모바일에서도 쾌적하게 플레이할 수 있습니다.

---

## 🛠️ 기술 스택
- **프레임워크**: Next.js 14+ (App Router) / React 18 / TypeScript
- **스타일링**: Tailwind CSS
- **데이터베이스**: Neon PostgreSQL (서버리스)
- **테스트**: Vitest

---

## 💻 비전문가를 위한 실행 가이드 (로컬 실행 방법)

컴퓨터에 Node.js가 설치되어 있지 않다면, [Node.js 공식 홈페이지](https://nodejs.org/)에서 **LTS 버전(20 이상)**을 다운로드하여 설치해 주세요.

### 1. 프로젝트 다운로드 및 압축 해제
프로젝트 폴더를 원하는 경로에 위치시킨 후, 터미널(명령 프롬프트)을 열어 해당 폴더로 이동합니다.
```bash
cd web-bubble-bobble
```

### 2. 패키지 설치
필요한 라이브러리를 설치하기 위해 아래 명령어를 입력하고 엔터를 누릅니다.
```bash
npm install
```

### 3. 환경 변수 설정
프로젝트 루트 디렉토리에 `.env.local` 파일을 생성하고 아래 내용을 입력합니다. (Neon PostgreSQL 연결 주소가 필요합니다.)
```env
DATABASE_URL=postgres://user:password@host:5432/database?sslmode=require
```
*(주의: 데이터베이스가 없어도 메모리 혹은 기본 구조로 빌드 테스트가 가능하며, 정식 연동 시 Neon 콘솔에서 발급받은 URL을 입력하세요.)*

### 4. 개발 서버 실행
설명이 완료되면 다음 명령어로 로컬 개발 서버를 실행합니다.
```bash
npm run dev
```

### 5. 게임 접속하기
브라우저를 열고 아래 주소로 접속합니다.
- `http://localhost:3000`

---

## 🧪 테스트 실행
자동화된 수용 테스트 및 단위 테스트를 실행하려면 아래 명령어를 입력하세요.
```bash
npm test
```
